SCALING EXAMPLE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Viewport: 600px wide × 800px tall
Canvas: 1080px × 1920px

Scale calculation:
  scaleX = 600 / 1080 = 0.556
  scaleY = 800 / 1920 = 0.417
  scale = Math.min(0.556, 0.417) = 0.417

Result:
  Visual width: 1080 × 0.417 = 450px
  Visual height: 1920 × 0.417 = 800px
  Font appears as: 48px × 0.417 = ~20px visually
  Actual font-size: 48px (unchanged in code)
