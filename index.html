Slide Studio

Welcome to SlideStudio.

I started this project because I couldn't find any app or service, online or in any app store, that produced consistent results when preparing images for Instagram. I wanted to match posts in 1:1 or 4:5 with stories, and there was always some manual adjustment required.

I prefer not to use ads. This project takes a considerable amount of time, and it also involves real costs for server hosting and bringing in external developers when needed. If you want to support the project, donations are appreciated.
